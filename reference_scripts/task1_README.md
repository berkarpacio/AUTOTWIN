Task 1 — Maximum Range/Endurance in Constant TAS and Constant Altitude Cruise Missions
-------------------------------------------------------------------------------------------------------

What it does
- Analytical and numerical calculations for propeller aircraft max endurance and max range in cruise.
- Two mission models: constant TAS with changing altitude, and constant altitude with changing TAS.
- Plots mass, range, TAS, and density histories for each scenario and prints the results for analytical and numerical studies.

How to run
1) Install deps: `pip install ambiance numpy matplotlib`.
2) From this folder: `python task1_code.py`.
3) The console shows analytical and numerical results for max range/endurance in constant TAS and constant altitude cruise ; matplotlib pops up four 2x2 subplot figures.
